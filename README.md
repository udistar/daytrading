# daytrading

키움 REST API로 돌리는 **변동성 돌파 데이트레이딩 봇**입니다. 모의투자부터 시작합니다.
Python 3.9 이상의 표준 라이브러리만 쓰므로 설치할 패키지가 없습니다.

## 전략 (Tradein 앱 설계 그대로)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 목표가 | 시가 + **K 0.5** × 전일 (고가 − 저가) | KRX 호가단위로 올림 |
| 진입 | 09:00–10:00 | 현재가가 목표가에 닿으면 시장가 매수. 종목당 하루 1번 |
| 손절 | 진입가 −2% | |
| 트레일링 스톱 | 진입 후 최고가 −3% | 진입가보다 높은 고점이 나온 뒤부터 작동 |
| 타임컷 | 15:18 | 15:20 종가 동시호가가 시작되기 전에 전량 매도 |
| 건너뛰기 | 전일 변동폭이 시가의 0.5% 미만, 또는 상한가 도달 | |

## 리스크 한도 (`config.json`의 `risk`)

- 1회 매수 금액: 기본 100만 원
- 동시 보유: 최대 3종목
- 하루 최대 거래: 5회
- 하루 손실 한도: 기본 5만 원. 실현손실이 이 금액에 닿으면 그날 신규 진입을 멈춥니다.
- 긴급 정지: 실행 폴더에 `STOP` 파일을 만들면 신규 진입을 멈추고, 보유 종목을 바로 매도합니다.
- 매도는 어떤 한도에도 막히지 않습니다.

## 사용 순서

```bash
copy config.example.json config.json
```

키는 환경변수로만 넣습니다. 파일이나 채팅에는 쓰지 마세요. (Windows cmd 기준)

```bash
set KIWOOM_APPKEY=모의앱키
```

```bash
set KIWOOM_SECRETKEY=모의시크릿키
```

**1) 연결 점검.** 주문은 나가지 않습니다.
```bash
py main.py check --code 005930
```
토큰, 현재가, 일봉, 잔고 네 가지가 모두 응답해야 다음 단계로 갑니다.

**2) 백테스트.** 최근 20일 5분봉을 받아서 같은 엔진으로 돌려봅니다.
```bash
py main.py backtest --fetch 005930,000660 --days 20
```
K나 손절 값을 바꿔 비교할 수 있습니다: `--k 0.4 --stop 1.5 --trail 2 --entry-end 09:30`

**3) 페이퍼 트레이딩.** 실시간 시세로 판단하되 체결은 가상입니다. 장 시작 전에 켜 두세요.
```bash
py main.py run --codes 005930,000660 --mode paper
```

**4) 키움 모의투자 주문.** 모의투자 서버로 실제 주문을 넣고, 체결은 잔고 조회로 확인합니다.
```bash
py main.py run --codes 005930 --mode mock
```

**5) 실전.** 기본으로 잠겨 있습니다. `config.json`의 `"allow_real": true`와 `--real-money` 플래그가 둘 다 있어야 켜집니다.
모의투자로 충분히 검증하기 전에는 켜지 마세요.

기록은 `data/runs/날짜-모드/`에 남습니다.
- `trades.csv`: 거래 1건당 1줄
- `events.jsonl`: 모든 판단과 키움 API 요청·응답

`data/`는 커밋되지 않습니다.

## 구조

```
bot/strategy.py  변동성 돌파 규칙 (네트워크 없음, 테스트 대상)
bot/risk.py      진입 전 한도 검사
bot/broker.py    PaperBroker (가상 체결: 슬리피지·수수료·거래세 포함), KiwoomBroker (시장가 주문 + 잔고로 체결 확인)
bot/feed.py      실시간 시세(ka10001) / 5분봉 재생
bot/engine.py    시세 → 전략 → 리스크 → 주문 → 기록. 실매매와 백테스트가 같은 코드를 씁니다
bot/kiwoom.py    키움 REST 클라이언트 (토큰, ka10001, ka10080, ka10081, kt10000/kt10001, kt00018)
main.py          check / backtest / run
```

## 아직 확인이 필요한 것

- **API 응답 형식:** 시세(ka10081, ka10080)는 모의서버 실호출로 확인했습니다. 주문(kt10000/kt10001), 잔고(kt00018), 현재가(ka10001)의 필드명은 키움 가이드 기준으로 작성했고 아직 실서버로 검증하지 않았습니다. `check`와 첫 `--mode mock` 실행의 `events.jsonl`로 확인하세요.
- **비용:** 수수료율(기본 0.015%)과 증권거래세율(기본 0.20%)은 본인 계좌와 올해 세율에 맞게 `costs`에서 바꾸세요.
- **백테스트의 한계:** 5분봉 안의 가격 경로를 추정해서 계산합니다. 슬리피지는 기본 1틱입니다. 과거 결과가 수익을 보장하지 않습니다.
