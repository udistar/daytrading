# Time Machine 과 3중 승인 (v0)

시뮬레이션이며 예측이 아닙니다. 수익·승률을 약속하지 않습니다. 실주문, 결제, 실전 주소(`https://api.kiwoom.com`)는 사용하지 않습니다. 프로덕션 매매 준비가 된 상태가 아닙니다.

## 브로커 충돌

지시 원문에는 KIS 모의투자가 있습니다. 이 저장소의 `spec.md` 와 코드는 키움 REST 모의투자(`https://mockapi.kiwoom.com`)입니다. **기존 방식이 우선**이라 이번 작업의 브로커는 키움입니다. KIS 어댑터는 후속 과제이며 넣지 않았습니다.

아이디어만 참고했습니다. [day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill) (MIT, Copyright 2026 Jake Schincariol). 원본 파일은 복사하지 않았습니다.

## 자동 매매 경로

09:00~09:50 규칙 엔진(`strategy.py`, `session.py`, `execution.py`)과 기존 `risk.py` 의 일손실·종목 한도·VI·09:50 로직은 수정하지 않았습니다. Time Machine 은 그 모듈을 import 하지 않습니다. 승인 게이트는 그 위에 얹는 수동·복기 절차이고, 자동 핫패스에는 연결되어 있지 않습니다. 핫패스에 붙이는 것은 후속입니다.

## 실행

키 없이 내장 가짜 분봉(`900001` 샘플전자)으로 돕니다.

```bat
set PYTHONPATH=src
py -3 -m daytrading --timemachine --out docs\timemachine-sample.json --png docs\timemachine-sample.png
```

화면: **Time Machine** 탭 → **샘플 픽스처 실행**. 판정 문장은 엔진이 만든 문장을 그대로 보여 줍니다.

설정(그룹 **타임머신**): 분봉 1 또는 5(기본 5), 조회 세션 60, 최소 풀세션 20, 재현 10000, 시드 19, 시각 창 ±2봉, 청산 09:50, 정규장 09:00~15:30.

## 분봉

- 기본 TR: [ka11080 주식분봉차트정규장조회요청](https://openapi.kiwoom.com/guide/apiGuideContents/07/ka11080). POST `/api/dostk/chart`. 모의 도메인은 KRX만.
- Body: `stk_cd`, `tic_scope`, `upd_stkpc_tp`, `base_dt`. 응답 목록 키는 `result_list`.
- [ka10080](https://openapi.kiwoom.com/guide/apiGuideContents/07/ka10080) 도 같은 경로이며 목록 키는 `stk_min_pole_chart_qry`. 파서는 둘 다 읽습니다.
- 문서 예시의 `tic_scope` 가 비어 있으나 Body 표는 필수입니다. 표의 값을 보냅니다.
- 연속조회 헤더 `cont-yn`, `next-key`. 모의 TR 간격은 장중 토큰버킷과 따로, 기본 1초입니다.
- **미확인**: 분봉을 최대 며칠 주는지는 공식 문서에 없습니다. `tm_lookback_sessions`(기본 60)만 요청 상한으로 두고, 풀세션이 20개 미만이면 이유와 함께 거절합니다.

풀세션은 **09:00~15:30 분봉이 빠짐없이 있는 날**입니다. 봉 개수는 시계와 `tic_scope` 로 계산합니다. KRX 조기폐장·휴장 공식 캘린더는 이 버전에 넣지 않았습니다. 봉이 빠지면 그 날은 풀세션이 아닙니다. 계획일과 그 이후는 풀에서 뺍니다.

## 재현

1. 풀세션의 봉 OHLC 를 직전 봉 종가 대비 비율로 저장합니다. 첫 봉은 그 봉의 시가 대비입니다.
2. 진입 시각부터 청산 시각 전 봉을 걷습니다. 같은 시각 ±창에서 과거 봉을 고른 뒤 현재가에 곱합니다.
3. 같은 봉에서 손절과 목표가 모두 닿으면 **손절을 먼저** 봅니다.
4. 시드와 횟수로 같은 숫자가 다시 나옵니다. 결과: 목표 먼저, 손절 먼저, 둘 다 아님, 비용 차감 후 이익, 평균 R, 청산가 분위수.
5. 히스토리: 09:05(설정의 신규 진입 시작) 이후, 직전 N분 고가를 돌파한 첫 봉에 그 가격으로 진입했다고 보고 같은 손절·목표 비율을 과거 풀세션에 다시 적용합니다. 이 규칙은 Time Machine 안에만 있습니다.
6. 판정은 손절 또는 목표에 닿은 재현만 봅니다. 목표 비율과 비용 차감 후 손익분기 `1/(1+R)` 의 차이가 5%p 안쪽, 5~15%p, 15%p 이상인지로 문장이 갈립니다.

## 3중 승인

1. **Risk PASS**. 종목·방향·수량·가격·유형·손절·목표·사유·금액의 지문. 매수는 기존 `veto_buy` 결과만 사용합니다. 오늘 그 지문만 유효합니다. `state/risk_verdicts.jsonl` 에 남습니다. PASS 는 매수 추천이 아닙니다.
2. **이 주문 번호만 「예」**. 「전체 예」「항상 허용」은 받지 않습니다.
3. **Allow once / Deny**. Always allow 는 없습니다.

하나라도 없거나 지문이 바뀌면 기록 함수를 부르지 않습니다. 거절 이유는 게이트 로그에 남습니다. 청산(매도)은 하루 손실로 BLOCK 하지 않습니다. 일손실 100만, 완충 70만, 종목 1,000만, 매수 5회, 동시 보유, VI, 09:50, 연속 손절은 게이트 안에 다시 적지 않았습니다.
